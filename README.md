# Social-Simulation-Workshop-October-2026
This social simulation workshop material was created for [the Simulating Social Worlds Workshop](https://himada2018.github.io/projects/social-simulation/workshop/) (October 21st &amp; 22nd, 2026). The workshop was funded by the British Academy through the Talent Development Award to Dr. Hirotaka Imada (TDA25\250048: [Advancing Theoretical Understanding and Methodological Capacity in Psychology Through Social Simulation](https://himada2018.github.io/projects/social-simulation/)).
